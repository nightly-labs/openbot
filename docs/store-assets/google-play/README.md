# Google Play screenshots

Phone screenshots for the OpenBot listing in Google Play.

- Size: 1389 × 2778 px (portrait, 1:2). Google Play does not accept a long side that is more
  than two times the short side, so these files are wider than the App Store files.
- Format: 24-bit PNG without an alpha channel. Each file is less than 8 MB.
- Source: Figma file "OpenBOT-AI", page "Sandbox", frames named `Google_Play`. Each frame was
  made 105 px wider for the export, with the content in the center.

The screens use sample data.
