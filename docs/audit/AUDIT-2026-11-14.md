## Plan: minimal diff viewer (step 1 only)

1. Shared `DiffView` component in `packages/ui` (old text + new text in, unified line diff out,
   +/- gutter, line numbers, added/removed counts). No new dependency.
2. Storybook story to check it visually.
3. Not in this step: keeping provider `oldText`/`newText`, IPC/Team API transport, a side-panel
   entry point. Each touches contracts and joined-server paths (AGENTS.md "Joined servers") and
   needs an approved issue upstream.
