### Added

- A chat bubble on Android. The bubble stays on the screen over other apps and shows a dot when an
  agent has a new message. Tap the bubble to read the chat in a small window. The setting is off by
  default. Turn it on for all agents, or for one agent only. Android must also allow bubbles for
  OpenBot. The app lock covers the bubble: while OpenBot is locked, the bubble shows no chat. A
  control in the bubble that opens another screen opens the app on that screen. This change needs a
  new app binary with a new runtime version before it can reach phones over the air.
