### Fixed

- When you attach an image to an OpenCode model that reads only text, such as OpenCode Seaglass Alpha Free, the message box now tells you that the model does not see the image. One click switches the agent to a free OpenCode model that reads images, and the chat and your message stay. Before, OpenBot sent the image, and the model answered only that it does not support image input. On a joined server, the server must also be on the new version.
