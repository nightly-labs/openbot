### Fixed

- On the Threads page and in the agent dock, a file link in an agent reply is now a file chip. Before, it showed as plain text, and a click did nothing. Now a click opens a document, a picture or a media file in its app on this computer. For other files, such as a script or a web page, it shows the file in its folder. In the web client, a click on the Threads page downloads the file. When the file cannot open, the app tells you why.
