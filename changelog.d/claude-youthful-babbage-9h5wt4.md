### Added

- Agents can now use the iPhone apps Calendar, Reminders, Contacts, and Location through the paired
  phone. Each app has an Allow switch in the iPhone app, and the iPhone asks for its permission when
  you turn the switch on. The host never skips this prompt, also in Full access mode.
- Agents can set a reminder before a calendar event: the agent reads the event on your phone and
  makes a routine that runs one time before it. The routine does not follow later changes to the event.
