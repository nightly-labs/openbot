### Added

- Server Settings > General has a new "Maximum agents" field. An owner or an admin sets how many
  agents a server can hold, from 1 to 1000. An empty field keeps the default of 100. New agents are
  blocked at the limit; existing agents are never removed.
- The field works on joined servers too: desktop, the web client and the phone show it when the
  server also runs this version, and hide it until then.
