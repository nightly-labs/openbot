### Fixed

- A hosted server no longer stays at "Starting" with "Too many active remote connections." Before, the phones, browsers and desktops of an account could use all its Signal connections, and Signal then refused the server's own connection. The account limit now counts only device connections. When a server or desktop connects again after a restart or a network change, connected devices move to its new connection.
- The server connection screen shows Signal errors in your language. Spanish now has the text of this screen.
