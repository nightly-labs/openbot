### Added

- Marketplace has a CoinMarketCap app. Agents can read crypto prices, market data, technical
  indicators, on-chain metrics and crypto news. Sign in to your CoinMarketCap account in the
  browser, or connect with an API key. The app only reads data: it cannot trade or move funds.

### Fixed

- When an app server does not accept your API key and sends an answer that OpenBot cannot read,
  the connect dialog now tells you to check the key. Before, it showed technical text.
