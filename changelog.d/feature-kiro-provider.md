### Added

- Kiro is now a provider. OpenBot runs the Kiro CLI that you installed (`kiro-cli acp`), and agents
  on Kiro run their chat, tasks and channel turns at the same time. Sign in with `kiro-cli login` in
  a terminal, then press Connect on the Kiro row. Kiro reads skills from `.kiro/skills` only, so the
  skills that OpenBot installs do not reach Kiro agents yet.
