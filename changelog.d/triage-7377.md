### Fixed

- When a provider sign-in, such as Grok, cannot connect to the provider because of the network or a
  proxy, OpenBot now tells you to check the network connection and the proxy of the computer that
  runs OpenBot. Before, it showed only "OpenBot could not connect Grok. Try again.", and each new try
  failed the same way. On a joined server, the server must also be on this version.
