### Added

- Claude agents: Settings → Providers → Claude has an Amazon Bedrock section. Turn it on, set the
  AWS region, and sign in with a Bedrock API key, AWS access keys or an AWS profile. You can also
  set a Bedrock model ID for the Opus, Sonnet and Haiku families. Keys and tokens stay encrypted on
  the computer that runs the agents. This also works for a joined server.
