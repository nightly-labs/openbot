### Fixed

- A workflow schedule that an agent sets for you now runs at that time in your time zone. Before, on a
  server, it could run in the server's time zone, for example one hour late. The trigger card shows
  the next run in the time zone of the schedule, and names that time zone when it is not yours. This
  needs the server on the new version too. To correct a schedule that an agent made before this
  change, ask the agent to set the time again.
