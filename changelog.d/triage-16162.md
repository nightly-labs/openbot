### Fixed

- A shared agent no longer changes your own skills. Before, when a shared agent had a skill with the
  same name as one of your skills, its text became a new version of your skill, and your other agents
  showed "Update available". Now the new agent gets its own copy, for example "helper 2". When you add
  the same shared agent again, its own copy gets the new version. Versions that an earlier install
  added stay in your library. On a joined server, the server must also be on this version.
