### Changed

- Show a specific reason when a connection to a server, the web app or a hosted server fails, for
  example when the host is busy, an invitation was already used or a firewall blocks the direct
  connection. Before, most of these failures showed "The connection failed."
- Show a short error code, with a copy button, under error messages and error notifications. Send
  this code when you report a problem, so we can find the cause.
