### Fixed

- When a joined server is offline, you can now switch to a different server, open the agent list and use all buttons while OpenBot tries to connect again. Before, each new attempt (Retry, a restart of the app, or a new selection of the server) covered the full window with the loading screen, and the app did not respond to clicks until the attempt stopped. When you close the "offline" message, the server area now shows the same message with Retry and Details.
