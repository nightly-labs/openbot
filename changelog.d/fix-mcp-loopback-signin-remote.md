### Fixed

- Sign in now works for an MCP server that runs on the same computer as a joined server, at an address such as `http://127.0.0.1`, when you use OpenBot on another computer or in the web client. For an owner or admin, the server opens the sign-in page in its own browser, and you sign in through the live view. A member sees that only an owner or admin of the server can do this sign-in. Before, the sign-in stopped with "The sign-in address is not a web page.", and you could not finish it.
