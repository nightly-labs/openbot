### Fixed

- A site that asks for its username and password in its own browser prompt (HTTP Basic sign-in) no longer shows only an empty page. The browser view now shows a **Sign in to** box above the page. Type the username and password, then select **Sign in**. If the site does not accept them, the box tells you, and you can try again. The agent can also ask you to take over, and you sign in from the same box. This works only for sites that use HTTPS. A joined server must also be on the new version for this.
