### Added

- The Marketplace has an X app. Set up adds the X agent and tells you how it works: reply to a post on X, mention @openbot_, and the OpenBot extension for Chrome sends the post to the X agent. The app shows the agent and a link to the extension. It works on this computer and, for an admin, on a joined server, in the desktop app and in the web client. A member of a joined server does not see the X app, as with Discord and the other chat apps.

### Changed

- On desktop and web, the X agent is no longer in the Agents tab of the Marketplace. Add it with the X app.
