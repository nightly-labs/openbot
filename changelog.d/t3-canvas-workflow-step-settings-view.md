### Added

- On the workflow canvas, LLM, condition, agent and image steps have a "Settings" action. It shows
  the settings and inputs that made the shown result. "Use these settings" puts them back into the
  step, so that you can run the step again with the same settings. Results from before this release
  have no saved settings. On a joined server, the server must also be on this version.

### Fixed

- The toolbar of a workflow node no longer opens under the canvas tools or the workflow header.
