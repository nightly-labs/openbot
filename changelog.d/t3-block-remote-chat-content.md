### Added

- A new server setting, "Load remote content in chats" (Server Settings > General > Privacy). It is off by default. While it is off, chats load nothing from other web sites until you click: a picture in a message or a Markdown file shows "Load picture", a diagram that names a picture shows "Load diagram", and agent pages, HTML file previews and backdrop pages show without scripts until you click "Run page". Owners and admins change the setting, and it applies to everyone on the server, on desktop, in the web client and on the phone. On a joined server, the server must also be on this version; until then, the app treats the setting as off.

### Changed

- Links in chats no longer show the icon of their web site until an owner or admin turns on "Load remote content in chats".
