### Fixed

- An agent that asks teammates for their results notifies you again when it answers with those
  results. Before, the answer of a coordinator that asked six teammates for a report gave no
  notification at all, because every turn that a teammate's message started was quiet. The teammates'
  own turns stay quiet. So does an agent's turn that passes a teammate's answer on to the agent that
  asked it. On a joined server, the server must also be on the new version.
