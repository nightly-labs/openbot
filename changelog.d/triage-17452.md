### Fixed

- When Codex live voice cannot start for a reason that OpenBot does not know, the message no longer tells you to update Codex and sign in with ChatGPT. That advice was wrong when you were already signed in, for example when OpenAI was busy or a usage limit was reached. The message now tells you to try again later, or to turn off live voice in Settings to talk by voice, and still gives the reason. A joined server shows the new message when it is on the new version.
