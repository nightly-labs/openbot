### Changed

- On a workflow image or video node that has a result, the prompt, references, model and Run button
  now show only while the pointer is on the node. When the pointer leaves, only the small tags stay,
  and you see all of the picture. The panel also stays open while you type in the prompt, use the
  keyboard in the node, or have one of its menus open. Click the Prompt tag to edit the prompt.
