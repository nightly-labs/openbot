### Added

- Add Elixir Games to the Apps catalog. Agents can answer the questions that your Elixir Games game
  builds wait on, so the builds continue while you are away. It works on macOS only. Install Elixir
  Games on the computer that runs OpenBot. In its Settings > Bots, turn on "Let your bots answer"
  and select Add a bot. Then paste the key of the bot in the connect dialog.
