### Added

- Server settings > Transfer can export a full copy of a server. Choose "Templates" for the agents and the server settings only, or "Everything" to also include the chat history, the channel messages, the workspace files and the server preferences. Each part also has its own switch, and a bar shows how much of the workspace files goes into the file. The server preferences are the time zone, personality, agent defaults, memory and skill settings, and your notification level; the import replaces the ones of the new server when you import the server settings. API keys, sign-ins and connector tokens are still never in the file.
- The web client can now export the chat history, the channel messages and the server preferences of a server too, in parts, so the file can be larger than 100 MB. **To export these parts from a joined server, update that server to this version too.**
