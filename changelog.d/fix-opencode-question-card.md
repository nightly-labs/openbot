### Fixed

- An OpenCode question with options now has one page in the question card. Before, the card also
  showed a second page, "Type your own answer". Now you type your own answer in the "Something else"
  row of the question.
- When you skip all questions in an OpenCode question card, the agent now continues. Before, the
  agent stopped and did not reply. To stop the agent, close the card.
- The text that OpenCode writes before it asks a question now shows as its reply above the question
  card. Before, this text was in the collapsed steps.
- On a joined server, these fixes need the server on this version.
