### Added

- openbot.run offers the Android app as an APK, for a phone with no Google Play. On the home page, the
  Android card has a "Get the APK" link and the download menu has an "Android · APK" entry. The
  Android download page has a second button with the install steps. The APK is the build that Google Play has, with the same signature. The download starts
  with the next Android version; version 1.4.9 has no APK.
