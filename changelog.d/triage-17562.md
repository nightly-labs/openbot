### Fixed

- When this computer cannot read the saved API key of a custom provider, for example after you move the provider list from another computer, you can now enter the API key again in the edit form and save it. Before, Submit kept the form open with the warning "This computer cannot read the saved API key and headers", and nothing was saved. Enter the headers again too when the provider needs them. On a joined server, the server must also be on the new version.
