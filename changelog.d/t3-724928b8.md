### Added

- Help → Report a problem opens the bug report form on GitHub with your OpenBot version and system
  already filled in.
- Agents can report a problem in OpenBot for you. Tell your agent what went wrong: it writes a short
  report in plain words, without technical questions, and adds the app version and your system. You
  read it and select Send report. OpenBot opens the issue on GitHub and your agent gives you its
  link. You do not need a GitHub account, and the issue does not show your name. When you are not
  signed in, you get the filled-in form to submit yourself.
