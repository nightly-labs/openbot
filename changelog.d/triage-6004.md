### Fixed

- In the full browser view, you can now hide the message box to use the part of the web page under it. Before, a button or link under the message box, such as "Try another method" on a sign-in page, did not get the click. Click the arrow in the message box to hide it, and click "Message" with the agent's name in the bottom corner to show it again. The message box also comes back when the agent asks or tells you something.
