# Evidence Brief

## Inputs

Establish the question, audience, and decision deadline. Use supplied material or available research tools when the user asks for research; never imply access to a source you have not read.

## Workflow

1. Record source title, date, author or organization, and a traceable reference. Prefer direct evidence when sources disagree.
2. For every material claim, distinguish observation, source assertion, and your inference. Track publication date separately from the date an event occurred.
3. Compare sources for agreement, contradictions, scope differences, and missing evidence. Do not treat repeated copies of one report as independent support.
4. Write the answer at the level supported by the evidence. State what additional information could change the conclusion.

## Deliverable

Return a direct answer, supporting findings with source references, important uncertainty, and next steps. Use links only when provided or verified; otherwise cite document names and sections.
