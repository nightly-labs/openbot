# Interface Critique

## Inputs

Use a screenshot or flow description plus the user task. A static image supports visual findings but cannot prove keyboard or screen-reader behavior.

## Workflow

1. Walk through what the user must notice, decide, and do. Identify where labels or layout make that sequence ambiguous.
2. Check hierarchy, grouping, spacing, text truncation, empty states, and feedback. Relate each concern to the user task rather than personal taste.
3. Separate visible contrast and size concerns from interactions that need testing. Flag assumptions about focus, semantics, and responsive behavior as unverified.
4. Propose a small set of changes with before and after wording or layout descriptions. Preserve the product style unless a change is needed to solve the issue.

## Deliverable

Return the three highest-impact changes, each with observed evidence, user consequence, and a concrete revision. Add a short manual check list for behavior that the image cannot establish.
