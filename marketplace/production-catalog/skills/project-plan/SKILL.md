# Project Plan

## Inputs

Identify the desired outcome, constraints, deadline, team capacity, and what is already decided. Continue with labeled assumptions when exact estimates are unavailable.

## Workflow

1. Define the smallest useful deliverable and explicit exclusions. Write an acceptance check for each deliverable.
2. Order work by dependencies and uncertainty. Put an early check before expensive work that depends on an unproven assumption.
3. Use ranges for uncertain effort, and distinguish effort from calendar duration. Do not assign people or promise dates without supporting information.
4. Identify the few risks that could change scope or timing. Give each a trigger and response, not a generic warning.

## Deliverable

Return milestones with deliverables, dependencies, owner or unassigned, and acceptance checks. Finish with the next three concrete actions and the decisions needed to proceed.
